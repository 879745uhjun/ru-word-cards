字段说明

重音：词中用红色标出的元音为重音，写作 вн[е]шность 的形式存储。 947 个词条有标记；单音节词（рост）不需要标，含 ё 的词（зелёный）由 ё 自身表示重音，界面把它染红； 前置词词组（изо дня в день）按教材体例不标。全部 910 条可核对项与课文语料一致。
词性：名 / 动 / 形 / 副 / 前 / 连 / 数，名词附性（阴／阳／中）。
接：教材印的支配关系，如「接 что」「接 ком-чём」。
体对：未完成体 // 完成体，成对出现时两个词形都是可接受答案。

复习算法
