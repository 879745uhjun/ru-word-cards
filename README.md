# 俄语单词卡 · 大学俄语 3

纯静态的俄语单词背诵卡，无框架、无后端、无构建步骤。打开 `index.html` 即用。

内容取自《大学俄语（东方）3》课后生词表：**12 课 · 1022 个词条**，逐词标重音，附中文释义、词性／性、支配（接格）与动词体对。

## 打开方式

- **本地**：双击 `index.html`（`file://` 直接可用，进度存在浏览器本地）
- **在线**：推送到 GitHub 后由 Actions 自动发布到 Pages

## 页面

| 页面 | 作用 |
|---|---|
| `index.html` | 书首页：封面、统计、12 课进度 |
| `study.html` | 背诵：正面俄语词，空格翻面看释义，1–4 自评 |
| `unit.html` | 本课全部：逐词状态、释义、语法 |
| `wrong.html` | 错题本：出过错的词、错次、上次时间 |
| `sources.html` | 来源、字段说明、版权 |

## 功能

- **四档间隔复习**：忘了 / 模糊 / 记得 / 轻松，按卡片系数递推下次复习日；间隔满 21 天记为「已掌握」
- **今日队列**：先到期的复习，再补新词（默认每天 20 个，可点「再学 10 个」加量）
- **重音渲染**：数据写作 `вн[е]шность`，页面把方括号里的元音染红并加注重音符
- **筛选**：按课次过滤，`study.html?lesson=3` 可直接进第 3 课
- **左右键切词**：`←` / `→`（或页面上的两个按钮）在不评分的情况下前后翻词，不认识的也能直接跳过
- **键盘**：`空格` 翻面、`1`–`4` 评分、`←` `→` 切词、`U` 撤销
- **暗色模式**：跟随系统 / 浅色 / 深色，默认浅色，切换按钮在导航最右
- **汉→俄**：卡片可以反过来出（题干中文，翻面看俄语），方向记在本机
- **错题本**：评「忘了」记一次错，单独一页按错次排序，可一键复习
- **重音**：标在元音上并染红；`ё` 自带重音，染色但不加重音符
- **列表可展开**：「本课全部」点词条就地展开词形表
- **变格/变位**：名词六格单复数、动词现在时与过去时、形容词性数表（887 张，90% 格子带重音）
- **例句**：卡片翻面显示 1–2 条课文原句，目标词高亮（888 条，覆盖 847 词）
- **搜索**：本课页可按俄语或中文过滤
- **导入 / 导出**：首页可把进度导出成 JSON，换设备再导入（会校验是不是同一本词书）
- **本地存储**：进度只存 `localStorage`，不上传
- **PWA**：`sw.js` 预缓存全部静态资源，可离线、可添加到桌面

## 重音

1022 个词条里 **947 个标了重音**，其余：

| 情况 | 数量 | 处理 |
|---|---|---|
| 单音节（`рост`、`шанс`） | 50 | 不需要标 |
| 含 `ё`（`зелёный`、`учёный`） | 24 | 界面把 `ё` 染红，不加点 |
| 前置词词组（`изо дня в день`） | 1 | 教材体例不标前置词 |

标注不是猜的：`tools/check-stress.js` 会拿带重音的课文语料逐词核对，
**910 条可核对项全部一致**。

```bash
node tools/check-stress.js data/course.js <课文目录>
```

## 变格与变位

表格由 `pymorphy3` 生成，再用课文语料回填重音（语料里出现过的词形才标，标不到的留空）：

```bash
python tools/build-forms.py <dxey.pack.json> <课文目录>
```

| 类型 | 张数 | 内容 |
|---|---|---|
| 名词 | 460 | 一至六格 × 单复数 |
| 动词 | 202 | 现在时/将来时 6 个人称、过去时四性、不定式 |
| 形容词 | 225 | 阳/阴/中/复 |

7632 个格子里 6905 个带重音（90%）。

## 数据

`data/course.js` 由 `build-data.js` 从词书包生成：

```bash
node build-data.js <dxey.pack.json 路径> [课文目录]
```

第三个参数是教材的提取目录（含 `第N课/第N课全课原文_带重音.md`），用于抽取例句；不传则只生成词条，卡片不显示例句。

词条字段：

| 字段 | 含义 |
|---|---|
| `ru` | 俄语词形，`[е]` 标重音 |
| `zh` | 中文释义 |
| `pos` | 词性：名 / 动 / 形 / 副 / 前 / 连 / 数 |
| `gender` | 名词的性：阴 / 阳 / 中 |
| `gov` | 支配（接格），如 `что`、`ком-чём` |
| `aspect` | 动词体：未完成体 / 完成体 |
| `kind` | `word` / `pair`（体对）/ `phrase`（词组） |
| `alt` | 体对的另一个词形 |
